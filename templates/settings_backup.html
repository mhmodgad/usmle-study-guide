Cloud backup

Every change is saved on this computer the moment you make it. Cloud backup copies what you choose to Google Drive (or any rclone remote) in the background. If you're offline it simply waits. Files are stored unencrypted.

When

What to back up

Untick anything you don't want in the cloud. The last three are large and can be rebuilt from your own copies, so they start unticked.

Where

Set up Google Drive (one time)
  1. Install rclone: Linux/macOS curl https://rclone.org/install.sh | sudo bash · Windows winget install Rclone.Rclone (or run the setup script again).
  2. In a terminal run rclone config create tempu-drive drive scope=drive.file. A browser opens; sign in to Google and allow access. drive.file lets rclone see only the files it creates.
  3. Type tempu-drive:tempu-backup above, press Test connection, then Save.

Keep

Restore from the cloud

Pick a backup and what to bring back. Only the ticked kinds of data are replaced; everything else stays as it is. A copy of your current data is kept in data/backup/ first.
